# لعبة المزاد 🔥

لعبة مزاد جماعية باستخدام Node.js + Express + Socket.IO.

- الشاشة: `/` أو `/display`
- اللاعب: `/player`
- رمز الغرفة: 4 أرقام
- كل لاعب يبدأ بـ 1000 نقطة
- 10 جولات، 15 ثانية لكل جولة
- يوجد مسار `/health` للتأكد أن Render يشغل السيرفر

## Render
- النوع: Web Service
- Runtime: Node
- Build Command: `npm install`
- Start Command: `npm start`
- Root Directory: اتركه فارغًا إذا كانت الملفات في جذر المستودع.

بعد النشر افتح رابط الخدمة مباشرة؛ الصفحة الرئيسية تنشئ غرفة شاشة تلقائيًا.
